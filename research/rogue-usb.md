## What a Rogue USB Device Is

A **rogue USB device** is a USB drive that's been secretly rigged to attack a computer instead of just storing files. Someone plants it on purpose, hoping a stranger will plug it in.

This is exactly what happened in the NovaPay incident — an employee found a USB outside the office, plugged it in to find the owner, and the computer started acting weird right after.

## Why Unknown USB Devices Are Dangerous

- You can't tell what's on it just by looking at it
- It can look totally normal while secretly running harmful code
- Some attacks start the second you plug it in no clicking needed
- Antivirus software doesn't always catch it

## How USB Devices Spread Malware

- **Auto-run tricks** — some computers automatically run programs the moment a USB is inserted
- **Disguised files** — a virus can be hidden inside a file that looks harmless, like "Resume.pdf"
- **Fake keyboard trick** — the USB pretends to be a keyboard and secretly types commands to install malware, all in a split second
- **Hidden in the USB itself** — some malware hides in the USB's internal software, so you can't find it just by scanning the files
- **Silent data theft** — some USBs are built to copy files off your computer without you noticing

This is likely how NovaPay's USB incident led to Possible Keylogging — a keylogger being installed to steal passwords.

## Why Employees Should Never Plug In Unknown USBs

- You can't check if it's safe just by looking
- Damage can happen instantly, before you even notice
- One infected USB can spread across the whole company network
- It can lead straight to stolen passwords and data breaches — which is exactly what happened at NovaPay

## USB Security Policies Companies Can Use

- Turn off USB ports by default on company computers
- Only allow approved, company-owned USB drives
- Require staff to hand in any found USB to IT instead of using it
- Have IT check unknown USBs on a separate, safe computer
- Use software that watches for unusual USB activity
