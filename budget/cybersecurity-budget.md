## Why Each Item Made the List

### 1. Endpoint Security — ₦120,000
- **Why needed:** The USB device that infected a computer could have been caught here.
- **Risk it fixes:** Malware spreading through the company.
- **Why chosen:** Every computer needs this — it's the most basic protection.
- **Why this budget:** It's cheap per device, so full coverage is affordable.
- **If not funded:** Malware can spread unnoticed, just like the USB incident.

### 2. Cybersecurity Training — ₦150,000
- **Why needed:** A staff member plugged in an unknown USB — a training gap.
- **Risk it fixes:** Human error, the #1 cause of most breaches.
- **Why chosen:** Cheapest way to prevent the widest range of mistakes.
- **Why this budget:** Training everyone once a year is low-cost, high-impact.
- **If not funded:** Staff will keep making the same mistakes that started this incident.

### 3. Password Manager — ₦90,000
- **Why needed:** Leaked passwords showed up on the dark web.
- **Risk it fixes:** Weak or reused passwords.
- **Why chosen:** Simple tool, big improvement in password strength.
- **Why this budget:** Very affordable per employee.
- **If not funded:** Employees keep reusing weak passwords, making future leaks worse.

### 4. Backup Solution — ₦300,000
- **Why needed:** If an attack destroys or locks data (like ransomware), NovaPay needs a way back.
- **Risk it fixes:** Permanent data loss.
- **Why chosen:** No other fix undoes actual data destruction — backups are the only safety net.
- **Why this budget:** Reliable backup storage costs more, but it's the last line of defense.
- **If not funded:** A serious attack could destroy company data with no way to recover it.

### 5. USB Security Software — ₦150,000
- **Why needed:** Directly addresses Event 1 — the actual USB incident.
- **Risk it fixes:** Rogue/unauthorized USB devices.
- **Why chosen:** Blocks the exact attack that already happened.
- **Why this budget:** Covers all 30 devices at a reasonable rate.
- **If not funded:** The same USB-based attack could easily happen again.

### 6. Multi-Factor Authentication — ₦100,000
- **Why needed:** A suspicious login happened using stolen credentials.
- **Risk it fixes:** Stolen passwords being used to log in.
- **Why chosen:** One of the strongest, cheapest defenses available.
- **Why this budget:** Low cost per user for a major security boost.
- **If not funded:** Any leaked password instantly gives an attacker full access.

### 7. Firewall — ₦200,000
- **Why needed:** Protects the whole company network, not just individual devices.
- **Risk it fixes:** Malware communicating with attackers, or unauthorized network access.
- **Why chosen:** A network-wide safety layer that supports everything else.
- **Why this budget:** A proper business firewall costs more but protects everyone at once.
- **If not funded:** Malware can freely send stolen data out, or attackers can get in more easily.

### 8. Security Monitoring Tool — ₦200,000
- **Why needed:** The suspicious login was only noticed by chance.
- **Risk it fixes:** Attacks going unnoticed for too long.
- **Why chosen:** Turns "lucky discovery" into automatic detection.
- **Why this budget:** Monitoring tools are a bigger investment, but catch problems fast.
- **If not funded:** Future attacks might not be noticed until real damage is done.

### 9. Virtual Card Service — ₦50,000
- **Why needed:** NovaPay's real card is exposed with every online purchase.
- **Risk it fixes:** Payment fraud from a stolen card number.
- **Why chosen:** Cheap way to protect the company's actual finances.
- **Why this budget:** Low cost, since it's mainly a service subscription.
- **If not funded:** A single leaked card number could compromise all company payments.

### 10. Contingency Fund — ₦140,000
- **Why needed:** Unexpected costs always come up in real projects.
- **Risk it fixes:** Running out of budget mid-implementation.
- **Why chosen:** Smart planning always includes a buffer.
- **Why this budget:** Whatever's left after the essentials are covered.
- **If not funded:** NovaPay could get stuck if any tool costs more than expected.
